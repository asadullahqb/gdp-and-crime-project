# GDP and Crime Project (Malaysia)

University data-science coursework (WQD7006) that predicts district-level crime in Malaysia from socio-economic features.

## Contents
- `Week 0/`–`Week 3/` — notebooks for data assessment, massaging, merging, regression, and clustering.
- `data/` — raw and massaged datasets sourced from OpenDOSM (population, birth, household income, crime, GDP).

## Tech
Python, Jupyter, pandas, scikit-learn (regression and clustering).
